# 贷款合同审查助手

面向银行与持牌金融机构的贷款合同智能审查智能体：上传合同，逐条比对 40 条审查规则，
输出带**原文定位**、**风险等级**、**可直接采纳的修改建议**的结构化审查意见。

> 完整项目（含上传解析服务、双栏联动前端、部署包、评测数据集）见
> **[GitHub 仓库地址]**。

## 能力

| 能力 | 说明 |
|---|---|
| 逐条审查 | 40 条规则，覆盖利率、担保、违约、合规四类 |
| 原文定位 | 每条风险给出条款号与原文片段，定位精确到字符 |
| 风险分级 | 高 / 中 / 低，附判定理由与对出借人的不利后果 |
| 修改建议 | 给出可直接替换的条款表述 |
| 授信比对 | 合同要素与授信批复不一致时提示（金额、利率、担保、期限、放款条件） |
| 结构化输出 | 严格 JSON，便于下游系统消费 |

## 导入方式

1. Nexent 控制台 → 智能体开发 → **导入** → 上传本目录的 `agent.json`
2. 平台会自动创建智能体（提示词、模型、知识库检索工具均已包含）
3. **补充一步**：把知识库 `contract-rules` 添加到该智能体
   （来源为本项目 `data/kb/rules-full.md`，40 条规则）
4. 模型自定义参数 `temperature = 0`（降低输出波动，导入后需手动补）

## 依赖

| 项 | 说明 |
|---|---|
| 模型 | `deepseek-chat`（或任意 OpenAI 兼容模型） |
| 知识库 | `contract-rules`，内容为 40 条审查规则 + 合规范式 |
| 向量模型 | 任一 embedding 模型（本地推荐 `bge-m3`） |
| 自定义 Skill / MCP | 无 |

## 设计要点

1. **定位不交给模型**：条款切分与字符偏移由调用方代码完成，模型只判断是否违反规则
2. **判定闸门写在提示词**：知识库只描述"什么算问题"，"什么不算问题"放在系统提示词
3. **规则两级分类**：有客观判据的规则计入指标，需主观权衡的仅作提示

详见 `prompt.md` 与完整项目的 `DESIGN.md`。
